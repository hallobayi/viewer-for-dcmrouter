Cara menggunakan
1. Extract file viewer.exe ke folder dcmrouter berdampingan dengan main.exe
2. Jalankan main.exe (jika sudah jalan tidak perlu restart)
3. Jalankan viewer.exe
4. Buka browser dan arahkan ke  http://localhost:5100/

Cara integrasi simrs dengan modality
1. Kirim payload fhir bundle ke
2. Lakukan query (f-find) dari alat ke port 5200
